# SecureAudit AI — API

Backend FastAPI para SecureAudit AI.

## Requisitos

- Python 3.12+
- PostgreSQL 16+
- pip

## Instalación

```bash
# Crear entorno virtual
python3 -m venv .venv
source .venv/bin/activate

# Instalar dependencias
pip install -r requirements.txt

# Copiar variables de entorno
cp .env.example .env
# Editar .env con tus valores
